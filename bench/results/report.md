# M0 benchmark report: local Polish TTS on CPU

This file is generated by `bench/report.py` from `bench/results/raw/*.json`. Do not edit it by hand.

All values in sections 1-8 are measured on the machine in section 9. Section 10 compares them with claims from `research.md`. Those claims are not verified here.

## Definitions

- **TTFA** (time to first audio): time from the synthesis call to the first audio chunk, model already loaded.
- **RTF** (real-time factor): synthesis time divided by audio duration. Lower is faster. 0.5 means 2x faster than real time.
- **Cold start**: time from process start (before the Python interpreter starts) to the first audio chunk of S1. The operating system file cache was warm (the benchmark cannot drop caches without root).
- **Peak RSS**: maximum resident memory of the whole process, from `wait4()` (same value as `/usr/bin/time -v`).
- **CPU cores**: process CPU time divided by wall time during synthesis.
- **Warm protocol**: 3 warm-up runs, then 10 measured runs for each text. p95 of 10 values is close to the maximum.
- **Thread configuration** `tXcY`: X intra-op threads, process pinned with `taskset` to Y CPUs.
